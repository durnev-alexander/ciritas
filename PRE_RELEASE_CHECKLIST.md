# CIRITAS v4 — чек-лист перед первым размещением

## Код и конфигурация

- [ ] Используется ветка `v4-orders`.
- [ ] `config/local.php` создан на хостинге и не находится в Git.
- [ ] Указаны реальные параметры подключения к БД.
- [ ] Указаны абсолютные пути к `Uploads` и `photos`.
- [ ] Настроены логин администратора и хэш пароля.
- [ ] После создания почтового пользователя заполнены `mail.order_to` и `mail.from`.

## Система

- [ ] PHP 8.1+.
- [ ] `pdo_mysql` включён.
- [ ] `mbstring` включён.
- [ ] `/admin-modern/system-check.php` не показывает критических ошибок.
- [ ] HTTPS работает на тестовом адресе.

## Публичная часть

- [ ] Главная страница открывается.
- [ ] Каталог продуктов загружается из существующей БД.
- [ ] Группы продуктов не показываются пользователю.
- [ ] Старые ссылки `product.php?id=...` работают.
- [ ] Старые ссылки `download.php?id=...` работают.
- [ ] Изображения из `photos` отображаются.

## Корзина и заказ

- [ ] Добавление лицензии в корзину работает.
- [ ] Несколько позиций в одной корзине работают.
- [ ] Изменение количества и удаление позиции работают.
- [ ] Итоговая сумма рассчитана правильно.
- [ ] Заказ на организацию проходит.
- [ ] Заказ на физическое лицо проходит.
- [ ] Почта РФ не добавляет стоимость доставки.
- [ ] Курьерская доставка добавляет 1000 ₽.
- [ ] Дополнительная позиция из `PriceSectionID=7` добавляется в сумму.
- [ ] После оформления создана запись в `csOrders`.
- [ ] `cart.IsOrdered` содержит ID заказа.
- [ ] Позиции остаются доступны через `cart_items` для просмотра заказа.

## Админка

- [ ] Вход в `/admin-modern/` работает.
- [ ] Заказ виден в списке заказов.
- [ ] В карточке заказа виден состав корзины.
- [ ] Видны тип заказчика, доставка и дополнительная позиция.
- [ ] Старый `/admin/` остаётся доступен.

## Почта

- [ ] Если `mail.enabled=true`, заказ сохраняется даже при проблеме отправки письма.
- [ ] После создания почтового пользователя тестовое уведомление приходит на нужный адрес.

## Решение о публикации

Переключать основной сайт только после прохождения всех обязательных пунктов и резервного копирования действующего сайта и БД.
